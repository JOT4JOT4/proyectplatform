# Movil

Base inicial en Expo + React Native + TypeScript para la aplicación móvil.

## Requisitos

- Node.js 20 o superior
- npm

## Arranque

1. Instala dependencias con `npm install`.
2. Copia `.env.example` a `.env` y ajusta `EXPO_PUBLIC_API_URL` si tu backend no corre en `http://localhost:3000`.
3. Inicia la app con `npm start`.

## Scripts

- `npm start`: abre Expo.
- `npm run android`: lanza Android.
- `npm run ios`: lanza iOS.
- `npm run web`: lanza web.
- `npm run typecheck`: valida TypeScript.
